# Customer Churn Prediction & Analytics Dashboard

## Overview

A Machine Learning web application that predicts whether a telecom customer is likely to
churn. Built on the public **Telco Customer Churn** dataset, with a scikit-learn pipeline
reaching **~81% hold-out accuracy** (ROC-AUC ~0.84), using a **reduced set of 10 input
features** (down from the 19 raw columns) for a shorter, friendlier front-end form.

**The model is trained directly inside the EDA notebook** (`EDA.ipynb`), meant to be run
in **VS Code** — there is no separate training script. Running the notebook end-to-end
explores the data, cleans it, selects the top 10 features by importance, trains and
compares models, and **saves `model/model.pkl` to disk** ("downloads" it locally), which
both front ends then load:

- **Flask** multi-page app (prediction form, dashboard, analytics) with a mild, non-white
  color theme
- **Streamlit** single-page app for quick, interactive predictions

The notebook also includes an **Interview Prep** section (Section 10) with common
interview questions and ready-to-use answers about the project.

## 1. Train the model (inside the notebook, in VS Code)

Open `EDA.ipynb` in VS Code and run all cells top to bottom, or from the terminal:

```bash
jupyter nbconvert --to notebook --execute --inplace EDA.ipynb
```

The notebook:
1. Loads and cleans the data (duplicate check, missing-value imputation)
2. Explores churn drivers with EDA charts
3. Ranks features by importance and **reduces 19 raw features down to 10**
4. Trains and compares Logistic Regression, Random Forest, and Gradient Boosting
5. Evaluates the best model (confusion matrix, classification report, ROC-AUC)
6. **Saves `model/model.pkl`** — this is the "download" step; the file lands in the
   `model/` folder next to the notebook, ready for the front end
7. Includes example churn / no-churn inputs and an interview-prep Q&A section

Final accuracy: **~81%**, comfortably above the 80% target, on only 10 input features.

## 2. Run the Flask app

```bash
python app.py
```

Open: http://127.0.0.1:5000

## 3. Run the Streamlit app (alternative UI)

```bash
streamlit run streamlit_app.py
```

Both front ends load the same `model/model.pkl` produced by the notebook.

## Reduced Input Features (10, down from 19)

`tenure`, `Contract`, `MonthlyCharges`, `TotalCharges`, `InternetService`,
`OnlineSecurity`, `TechSupport`, `PaymentMethod`, `PaperlessBilling`, `MultipleLines`

**Predicts Churn (~92%):** tenure=1, Contract=Month-to-month, MonthlyCharges=99.75,
TotalCharges=99.75, InternetService=Fiber optic, OnlineSecurity=No, TechSupport=No,
PaymentMethod=Electronic check, PaperlessBilling=Yes, MultipleLines=Yes

TotalCharges=1304.80, InternetService=No, OnlineSecurity=No internet service,
TechSupport=No internet service, PaymentMethod=Credit card (automatic),
PaperlessBilling=No, MultipleLines=No
